# OXVOX Standalone Application

Aplikasi manajemen sistem lokal (System Manager) yang di-build menjadi binary asli.
Fitur:
- Informasi Sistem
- Terminal Command Execution (Lokal)
- File Explorer (Read-only)

Aplikasi ini TIDAK memiliki fitur RAT, stealth, atau persistence ilegal.
Hanya berjalan di localhost (127.0.0.1).

## Cara Menjalankan
1. Download file binary dari tab Actions di GitHub.
2. Ekstrak file zip artifact.
3. Jalankan file `oxvox-win.exe` (Windows) atau `oxvox-linux` (Linux).
4. Browser akan terbuka otomatis ke `http://localhost:8443`.
5. Login dengan username: `admin` dan password: `oxvox2026`.
